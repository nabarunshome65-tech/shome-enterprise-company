# Shome Enterprise — enhanced SEO package

This package is prepared for a Kolkata-first strategy, with accurate wording for project enquiries across India. It does **not** publish changes to GitHub automatically.

## Included files
- Six dedicated service pages: CCTV, networking, fire alarm, intercom, OFC and commercial sound systems.
- `contact.html`
- `assets/style.css`
- `sitemap.xml` (homepage + seven supporting pages)
- `robots.txt`
- `HOMEPAGE-NAV-SNIPPET.html` (links to add to the existing homepage)

## Upload steps
1. Download and extract the ZIP.
2. Open your repository: https://github.com/nabarunshome65-tech/shome-enterprise-company
3. Upload the six service HTML files and `contact.html` to the repository root, alongside your existing `index.html`.
4. Upload the complete `assets` folder so the stylesheet path remains `assets/style.css`.
5. Add the links in `HOMEPAGE-NAV-SNIPPET.html` to your current homepage navigation and relevant service sections. **Do not replace your current index.html.**
6. Replace or merge `sitemap.xml` and add/merge `robots.txt` in the root. The sitemap includes your existing homepage plus the new pages.
7. Commit changes and wait for GitHub Pages deployment. Test every page, call button and WhatsApp button on mobile and desktop.
8. In Google Search Console, submit `sitemap.xml`; inspect the new URLs and request indexing once.

## SEO improvements included
- Unique, service-specific title and meta description on each page.
- Canonical URL, Open Graph and Twitter metadata.
- Structured data using Organization, Service and BreadcrumbList where appropriate.
- Kolkata-first language; India-wide enquiries qualified by project availability.
- Contextual internal links, clear H1/H2 headings, useful scope information, enquiry instructions and mobile-responsive design.
- WhatsApp links use URL-safe encoded enquiry text.
- No fabricated street address, project counts, client claims, certifications, ratings or guarantees.

## Important SEO notes
- A sitemap helps discovery; it does not guarantee indexing or ranking.
- Avoid creating many near-identical city pages. Build location-specific pages only when you have real coverage, project evidence and genuinely useful local information.
- Google does not use the meta keywords tag for ranking; none is added.
- Use Google Search Console performance data to decide which page/query to improve. Review after several weeks, not every hour.
- Keep contact details consistent across the website and legitimate business listings.
